# Omarchy Plugins

Omarchy shell plugins by Erick Rodriguez.

## Plugins

| Plugin | Description |
| --- | --- |
| [Yamaha MG-XU Compatibility](yamaha-mg10xu-compat/) | Adds a Yamaha status widget and panel toggle for the user-level PipeWire capture keepalive that prevents playback stalls on affected Yamaha MG10XU/MG-XU mixers. |

Each plugin directory is self-contained. See its README for requirements, installation, usage, and removal instructions.
