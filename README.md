# Omarchy Plugins

Omarchy shell plugins by Erick Rodriguez.

## Plugins

| Plugin | Description |
| --- | --- |
| [Yamaha MG-XU Compatibility](yamaha-mg10xu-compat/) | Turn it on when an MG10XU/MG-XU mixer loses playback sound after a few seconds. Adds a Yamaha status widget and panel toggle for the user-level PipeWire capture keepalive. |

Each plugin directory is self-contained. See its README for requirements, installation, usage, and removal instructions.
